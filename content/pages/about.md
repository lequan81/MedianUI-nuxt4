Median UI is a Nuxt-based blog refactor focused on cleaner reading, tighter layout control, and markdown-driven content.

## What this project emphasizes

- Content first navigation
- Stable article spacing
- Shared layout components
- Markdown pages for static content

## Why markdown pages

Using markdown keeps the informational pages simple to maintain and consistent with blog posts.
